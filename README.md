# DeContradictor

Gemini Liveとの会話で、問題・原因（ボトルネック）・解決策の関係を図にする実験アプリです。TOC Thinking ProcessとTRIZを組み合わせる構想の、音声会話とフロー図の試作段階です。

3Dキャラクターは使用しません。Geminiの発言は青・ピンクのロボアイコンと9種類の感情表示、自分の発言はGoogleログイン後のプロフィール画像で表示します。ロボアイコンの色は常に選択した声に合わせます（女性系はピンク、男性系・中性的な声は青）。

## 起動

```powershell
npm install
npm run dev
```

表示されたURLの `/` が課題一覧です。TOPの「共通設定」でGemini APIキー、応答音声、会話の基本方針、自動同期を設定します。Googleアカウントと共通設定はTOPでのみ管理します。課題を作成・選択すると議論・作図画面が開き、「課題・保存」では課題名とJSON出力・読込を操作できます。共通設定を変更したいときは「課題一覧へ」でTOPに戻ります。

## 機能

- Gemini Liveの音声・テキスト会話と、必要時のGoogle検索
- 接続時にAIから一度だけ声かけ。新規は趣旨説明・UDEの聞き出し、再開は保存した図・直近の会話の振り返りと次の進め方
- UDEを自然な言葉で伝えると、AIが重複・包含・因果の仮説を整理して作図し、周辺の困りごとを少しずつ聞き出す対話方針
- 感情データとReact Flow形式の更新データを受信して表示
- ノード・矢印の手動編集、自動配置、拡大縮小
- 課題ごとの会話・フロー図のブラウザ内自動保存、JSON出力・読込
- TOPでのGoogleログイン、DriveとローカルをUUIDでまとめた課題一覧、同期状態と競合時の版選択
- Googleログイン中は未登録の課題も自動でDriveへ登録。課題ごとの同期開始操作は不要で、共通設定からこのブラウザ・アカウントの同期を停止・再開
- TOPの課題カードから確認付きで削除。Drive登録済みならDriveのゴミ箱へ移し、ローカルの課題・同期情報も削除
- プロフィール画像、APIキー・設定のDrive保存と会話・図のDrive同期
- アカウント変更時はLiveを停止・課題を保存してTOPを再読み込み。設定はアカウント別に復元し、未ログイン時は初期値で開始

Googleログイン設定と保存内容は [docs/live-account-and-save.md](docs/live-account-and-save.md) を参照してください。OAuthクライアントIDはソースに設定済みです。Googleログインなしでも会話とローカル保存は利用できます。

## 開発確認

```powershell
node --test tests/*.test.js
npm run build
```

`/tests/live-sync-ui.html` は、専用IndexedDBと模擬Driveを使った同期・退避・版選択の確認画面です。本番の課題やGoogleアカウントにはアクセスしません。
`/tests/common-settings-ui.html` は、メモリ内の設定と模擬アカウントで共通設定の共有・切替・停止・読込中の編集保護を検証します。
`/tests/live-facilitator-ui.html` は、模擬Live通信で初回・再開の声かけ、ロボ付きチャット、図の参照・差分検証を確認します。本番の課題やAPIにはアクセスしません。
