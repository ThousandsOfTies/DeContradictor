# Live画面のアカウント・保存

## 最初のGoogleログイン設定

1. Google Cloudで利用するプロジェクトを選び、Google Auth Platformの同意画面を設定します。外部向けでテスト中の場合、利用するGoogleアカウントをテストユーザーに追加します。
2. OAuthクライアントIDを「ウェブアプリケーション」で作成します。承認済みJavaScript生成元には画面に表示される生成元を登録します。例: `http://127.0.0.1:5174`。`http://localhost:5174`でも利用するなら、それも別途登録します。パス `/live.html` は付けません。
3. OAuthクライアントIDはアプリのソースに設定済みです。クライアントシークレットは使用しません。ローカル実行とGitHub Pagesで同じIDを使う場合は、両方の生成元をGoogle Cloudへ登録します。
4. 同じプロジェクトでGoogle Drive APIを有効にし、TOPの「Googleでログイン」を押します。プロフィール・Driveファイル・アプリ専用データへの許可を求めます。Googleアカウントの切替・再接続・ログアウトはTOPで管理します。自分の次の発言からGoogleの名前・プロフィール画像を表示します。
5. TOPの「共通設定」でAPIキー・声・会話の基本方針を設定します。すべての課題で同じ設定を使います。「共通設定をDriveへ保存」を押すと、ブラウザにそのアカウントの設定がないとき、ログイン後にDriveから復元します。共通設定のDrive保存は課題の自動同期とは別の明示的な操作です。変更後に別端末でも使う場合はもう一度保存してください。既存のブラウザ設定をDrive版へ置き換えたいときは「Driveの共通設定を読込」を使います。

GoogleログインそのものはGemini APIキーの代わりではありません。Driveに保存したキーをログイン後に取得して、Live接続へ使います。Googleログインなしでも、APIキーを入力して会話・課題のローカル保存を利用できます。未ログイン時の共通設定はタブのsessionStorageだけで一時共有し、TOPから課題へ移動しても再入力不要です。初回ログイン・アカウント変更・ログアウト時に一時設定を消して初期値から復元します。未ログインで新しいタブを開始した場合の初期値はAPIキー空、音声Puck、基本方針空です。ブラウザがタブを複製・復元する場合、sessionStorageも引き継ぐことがあります。

## 共通設定と課題ごとの操作

- TOPの「共通設定」: APIキー、キーをブラウザに記憶するか、応答音声、全課題の会話の基本方針、Drive自動同期の停止・再開、共通設定ファイルのDrive保存・読込・削除。
- ロボアイコンの色は常に応答音声に合わせます。女性系の声はピンク、男性系・中性的な声は青で、色の選択欄はありません。以前のブラウザ・Drive設定にある固定色の指定は無視します。保存済みの発言のアイコンは発言時の色を維持します。
- 実行画面の「課題・保存」: この課題の名前、ローカル保存、JSON出力・読込、今すぐ同期、競合やエラーの確認。Driveの他の課題はTOP一覧から開きます。
- 共通設定はTOPからのみ開けます。実行画面ではTOPで設定した内容を引き継ぎます。変更したいときは「課題一覧へ」でTOPに戻ります。声と基本方針の変更は次のLive接続から適用します。
- 自動同期は既定ON。ログイン・権限・ネットワークがそろっている間、起動時、ネットワーク復帰時、TOP表示復帰時に照合し、表示中は約30秒ごとにも照合します。会話・図の変更は約3秒後に送信します。アプリを閉じている間の常駐同期は行いません。
- 「Google Driveの自動同期」をOFFにすると、このブラウザ・このアカウントの自動送信・取得・欠落整理を停止し、ローカル保存は継続します。Driveの課題は消さず、OFFは次回起動後も維持します。再開すると最新Driveと照合して未送信分を同期します。停止設定はアカウント別localStorageに保持し、別端末やDrive設定には引き継ぎません。同じ保存領域の他のタブにも反映します。開始済みの通信を取り消す保証はありません。
- 停止の用途は、機密を含む内容をローカルだけで検討するとき、通信を控えたいとき、切替・不具合の確認中などです。通信断・認証切れは接続待ちになり、競合した課題は採用する版を選ぶまで自動上書きしません。

## アカウント切替と再起動

- ログイン済みの「Googleアカウントを切替」ボタンはアカウント選択画面を開きます。初回ログイン・別アカウントへの切替・ログアウトで利用者が変わると、TOPを再読み込みします。同じアカウントの再認証や、起動時の認証復元では再起動しません。
- 実行画面ではLiveを停止し、現在の課題をIndexedDBへ保存してからTOPへ移動します。保存に失敗した場合は移動せずエラーを表示します。切替時に新アカウントへ旧課題をアップロードすることはありません。
- アカウント変更時は一時設定を消して初期値から始め、認証が復元されたアカウントのブラウザ設定だけを読みます。そのアカウントのブラウザ設定がないときだけ、Drive設定から自動復元します。TOPでの編集やキー削除を、実行画面へ移動した際に古いDrive設定で戻しません。読込中に手元で変更した場合も上書きしません。設定がないアカウントは初期値のままで、別アカウントのAPIキーなどを引き継ぎません。
- APIキー・音声・会話ディレクションはGoogleの利用者IDごとにブラウザ内で記憶します。APIキーの記憶をOFFにしても、そのアカウントの声などの設定は保持します。以前のアカウント共通の設定は復元しません。旧保存データの自動削除・どちらかのアカウントへの自動移行もしません。
- 旧アカウントの課題・設定は保持します。TOPの課題一覧では現在ログイン中のアカウントに登録した課題とローカルのみの課題を表示します。未ログイン時は全ローカル課題を表示するため、ログアウトは共有PC上の閲覧保護にはなりません。

Googleが埋め込みブラウザでの認証を拒否する場合は、ChromeまたはEdgeでLive画面を開いてください。同じURLでもブラウザが異なるとローカル保存は別になります。

## 保存されるもの

- 課題一覧: TOP画面で課題を新規作成・選択します。課題には固有ID、名前、会話、図、保存日時と最終編集日時を持たせます。ローカルとDriveは同じUUIDなら1枚のカードにまとめます。以前の下書きと手動保存版は初回表示時に課題へコピーし、元データも残します。
- 自動保存: 会話とフロー図の編集を約0.6秒後に、その課題のデータとしてブラウザのIndexedDBへ保存します。課題一覧へ戻るときにも保存します。
- 今すぐ保存: 現在の課題を保存します。別の保存版は作りません。
- 課題の削除: TOPの各カードの「削除」から課題名と削除範囲を確認します。「ローカルのみ」はログインなしで削除でき、元に戻せません。Drive登録済みは登録したアカウントへのログイン・Driveの許可・ネットワーク接続が必要です。Driveの対象ファイルをゴミ箱へ移した成功を確認してから、ローカルの課題本文・同期情報・競合情報をまとめて削除します。APIキーなどの設定や他の課題は削除しません。
- 削除の安全策: Driveのアプリ識別・課題UUID・更新版を確認し、別端末で更新されたファイルや確認中に編集されたローカル版は削除しません。Driveへの接続失敗時もローカルは残します。削除中の別画面の追加編集は上書きせず残し、次の照合で必要に応じて別UUIDへ退避します。削除済みUUIDには移行用の印を残すため、旧下書きや旧同期リンクから勝手に復活しません。別画面で開いている課題の未送信編集は、新しいローカル課題として退避される場合があります。
- Driveからの復元: 送信済みの内容はDriveのゴミ箱から復元して、TOPの「同期・更新」で再取得できます。未送信の編集は復元できません。Google Driveのゴミ箱のファイルは通常30日後に完全削除されます（[公式説明](https://developers.google.com/workspace/drive/api/guides/delete)）。
- JSON出力/読込: 会話、各発言の感情・色・名前・プロフィール画像URL、直近300件の通信ログ、ノード・矢印・座標を扱います。音声、APIキー、OAuthアクセストークン、Googleメールアドレスは含めません。会話本文に機密情報を書けば、その本文は保存されます。共有前に内容を確認してください。
- Drive設定: APIキー・声・会話ディレクションを、Driveの隠しアプリ専用領域 `appDataFolder` に別ファイルとして保存します。初回は明示的な保存操作が必要です。`Drive設定を削除` はこのファイルだけを削除します。
- Drive同期: Googleログイン中かつ自動同期ONなら、一覧の完全な取得・検証が成功した後、未登録の課題にも自動でファイルを作ります。以後の編集は約3秒の待機後に同じファイルへ自動更新します。ローカルを先に保存し、Driveの最新内容と前回同期した内容を比較して送信します。送信中の追加編集は未送信のまま残して、次回送信します。
- 起動時の照合: TOPへログインすると、アプリがアクセスできるDrive一覧の全ページと各課題の本文を取得します。実行画面でも認証復元・停止中のログイン時に照合します。権限は `drive.file` と `drive.appdata` です。UUID導入前のDriveファイルにはファイルIDから安定した課題IDを付け、次の更新でUUIDをDriveにも保存します。
- 内容の採用: ローカルだけ変更ならDriveへ送信、Driveだけ変更ならローカルへ取得。両側で別々に変更された場合や、初回照合で比較基準がなく内容が違う場合は「競合」にして、どちらも自動上書きしません。TOPの「版を確認」で採用する版を選べます。もう一方は同じアカウントの新しいUUIDの課題として退避し、自動同期ONなら次回照合でDriveへ登録します。Live接続中はDrive版で実行中の表示を置換せず、停止後に照合します。
- 欠落キャッシュの整理: 同じGoogleアカウントで全ページ・全本文を正常取得して照合できた場合だけ、Drive一覧にない登録済み課題のキャッシュを削除します。未送信の内容や比較基準が不明な内容は「Drive未送信の退避」として別UUIDへコピーしてから削除します。Drive未登録の課題・別アカウントのキャッシュは削除しません。通信失敗、不完全な検索結果、不正な本文、重複UUID、ログアウトでは削除しません。整理した件数と退避の有無は画面に表示します。
- 状態表示: 「接続中」は起動後の照合待ち、「同期中」は変更の送受信中、「同期済み」は一致確認または送信成功後です。「接続待ち」「同期エラー」「競合」「同期停止中」も表示します。文字列の状態は保存せず、登録先アカウント・DriveファイルID・前回同期した内容のSHA-256などを課題本文とは別のIndexedDB管理レコードに保存します。未送信・未登録でも所属アカウントは別の `owner:<UUID>` レコードで保持するため、送信失敗後に別アカウントへ切り替えても自動送信しません。旧localStorageのDriveリンクは起動時に移行します。
- 更新日時と一致判定: 最終編集日時は課題名・会話・図を変更したときに更新します。保存操作や通信ログだけでは進めません。一致判定は保存日時・編集日時を除いた課題内容（通信ログを含む）の指紋で行うので、端末の時計や最後の発言時刻に依存しません。
- 他端末で復元できるのはDriveへの送信が成功した課題です。以前の未登録・所属不明なローカル課題は、最初の正常な照合後に現在ログイン中のアカウントへ登録します。すでに別アカウントへ所属・登録済みの課題はアップロードしません。新規課題・JSON読込・退避コピーも所属先を保持します。
- 読込: JSONは新しい課題として追加します。Driveから開く場合も上記の照合ルールで採用する内容を決めます。復元後も同じDriveファイルへ同期を続けます。Live接続中は実行画面から読み込めません。

上限は会話1000発言、各発言20000文字、ノード500件、矢印2000件です。長い会話は途中でJSON出力してください。保存データは表示を復元するもので、Geminiサーバー側の会話記憶は復元しません。

## 会話開始・再開とファシリテーション

- 「接続して開始」「テキスト専用で接続」のどちらも、Liveの準備完了後にAIへ最初の声かけを依頼します。接続ごとに1回です。接続失敗時は声かけを送らず、停止した古い接続の通知も無視します。
- 会話も図も空なら初回です。課題名・作成日時・通信ログだけでは再開扱いにしません。アプリの趣旨を短く説明し、困りごと（UDE）・関連する原因や周辺で改善したいことを順不同で話してもらうよう誘導します。タイトルだけから現象や図を作るようには指示しません。
- 会話または図があれば再開です。実際に保存された内容を短く振り返り、次の作業を1つ提案して質問します。挨拶しかなければ分析はこれからと案内します。音声とチャットは通常の応答経路を使い、内部の開始依頼はユーザーの発言として表示・保存しません。
- 新しいLiveセッションへ課題名・図・直近の会話の抜粋を渡します。会話は直近16発言まで、各1200文字・合計6000文字以内です。省略の有無をAIへ明示します。図は40ノード・80エッジずつ渡し、大きな図の残りは `get_issue_context` で取得できます。座標・プロフィール・通信ログ・設定ファイルはコンテキストに含めません。ただし会話本文や図に直接記した内容はAIへ送信されます。
- 図の変更や追加UDEの質問を考える前に、同じツールで現在の課題名・会話・図を再確認するよう指示しています。手で編集した内容も取得できます。以前のGeminiセッションそのものの復元ではなく、保存内容を参考にした再開です。
- 基本方針はTOC Thinking ProcessesとTRIZの対話ファシリテーターです。「フローを書いて」と言わなくても現象を図に整理し、AIが原因から結果への矢印を提案します。重複と包含を区別し、未確認の因果は仮説として表示、周辺のUDEを一度に1〜2点だけ尋ねます。拒否した候補を繰り返し押し付けたり、いきなり一般的な助言で終わらせたりしないよう指示しています。
- 図の差分は反映前に一式を検証し、存在しないノードへのエッジなどは現在の図を変更せずエラーをAIへ返します。これは構造の検証であり、因果関係の正しさまで保証するものではありません。聞き取り・推論・進行の品質は実際の対話で確認してください。
- コンテキストの入力と最初の応答もGeminiのトークン使用に含まれます。毎回全履歴を送る方式ではありません。Liveが入力を待つ仕様のため、アプリが最初の生成を開始する依頼を送ります（[公式の開始時の注意](https://ai.google.dev/gemini-api/docs/live-api/best-practices)、[会話コンテキストの送信](https://ai.google.dev/gemini-api/docs/live-api/capabilities)）。

## セキュリティと注意点

- 「このアカウントでブラウザに記憶」がONの場合、APIキーはアカウント別のlocalStorageに平文保存されます。Drive設定へ保存した場合も、APIキーはアプリ側で暗号化せずJSONとして保存されます。Googleによるアクセス制御はありますが、キーそのものを安全なサーバーに秘匿する方式ではありません。共有PCではブラウザへの記憶をOFFにしてください。
- 「このアカウントのキーを削除」はログイン中のアカウントのローカルAPIキーだけを消します。他のアカウントのキーは消しません。Drive上の設定は「Drive設定を削除」で別途消してください。
- Googleの短期アクセストークンはタブのsessionStorageにのみ保持します。有効期間を過ぎたらGoogleへ再接続してください。長期の自動ログインは行いません。
- ログアウトしても会話やアカウント別設定のローカル保存は残ります。LiveとDrive同期を停止してTOPを再読み込みします。過去の発言の名前と画像は、その発言時のものを維持します。Googleの認証期限切れもログアウトとして扱います。
- 同じ課題を複数端末で同時編集した場合、自動マージはしません。前回の同期基準から両側の内容が変わっていれば競合として残します。同一ブラウザのDrive処理はWeb Locksで直列化し、IndexedDBの置換・削除は照合時の内容が残っている場合だけ同一トランザクションで行います。別画面がキャッシュを更新した場合、実行画面の未送信編集は別UUIDへ退避します。厳密なリアルタイム共同編集機能ではありません。
- `localhost` と `127.0.0.1`、ポート番号が異なるURLは別の保存領域です。
- ブラウザデータ削除・プライベートモード・ストレージ制限でローカル保存が失われる場合があります。重要な会話はJSONまたはDriveに保存してください。

公式資料: [GIS token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model)、[Drive uploads](https://developers.google.com/workspace/drive/api/guides/manage-uploads)、[Drive検索と不完全な結果](https://developers.google.com/workspace/drive/api/guides/search-files)。

## 開発時の検証

`node --test tests/*.test.js` と `npm run build`。
Vite起動中の `/tests/live-ui.html` はロボ18表情とチャット連結・保存復元を確認するテスト専用画面です。Google/Geminiへ接続せず、本番の保存領域を変更しません。

`/tests/live-sync-ui.html` は専用名のIndexedDBで実トランザクションの置換・競合検知・ロールバック・削除前退避を検証し、模擬Driveで接続中・同期済み・競合と版選択を確認する専用画面です。Googleの認証・本番Driveへの送受信は行いません。
`/tests/common-settings-ui.html` はメモリ内の設定と模擬アカウントで、全課題共通の設定・匿名の一時共有・アカウント別の復元・同期停止・読込中の編集保護を検証します。本番の設定や認証にはアクセスしません。
`/tests/live-facilitator-ui.html` は本番HTMLの構成と実際のチャット・図・Liveクライアントを使い、メモリ内の課題と模擬通信で初回・再開・二重開始防止・コンテキスト取得・差分検証を確認します。発話例と音声再生は模擬で、GeminiやGoogleアカウントへ接続せず保存データも変更しません。
