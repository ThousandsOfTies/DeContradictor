# Live画面のアカウント・保存

## 最初のGoogleログイン設定

1. Google Cloudで利用するプロジェクトを選び、Google Auth Platformの同意画面を設定します。外部向けでテスト中の場合、利用するGoogleアカウントをテストユーザーに追加します。
2. OAuthクライアントIDを「ウェブアプリケーション」で作成します。承認済みJavaScript生成元には画面に表示される生成元を登録します。例: `http://127.0.0.1:5174`。`http://localhost:5174`でも利用するなら、それも別途登録します。パス `/live.html` は付けません。
3. OAuthクライアントIDはアプリのソースに設定済みです。クライアントシークレットは使用しません。ローカル実行とGitHub Pagesで同じIDを使う場合は、両方の生成元をGoogle Cloudへ登録します。
4. 同じプロジェクトでGoogle Drive APIを有効にし、Live画面の「Googleでログイン・同期」を押します。プロフィール・Driveファイル・アプリ専用データへの許可を求めます。自分の次の発言からGoogleの名前・プロフィール画像を表示します。
5. 「APIキー・設定をDriveへ保存」を押すと、以後のログイン時にDriveからキー・声・ロボの色・会話ディレクションを読み込みます。設定の変更後はもう一度保存してください。

GoogleログインそのものはGemini APIキーの代わりではありません。Driveに保存したキーをログイン後に取得して、Live接続へ使います。Googleログインなしでも「このブラウザに記憶」とローカル保存は利用できます。

Googleが埋め込みブラウザでの認証を拒否する場合は、ChromeまたはEdgeでLive画面を開いてください。同じURLでもブラウザが異なるとローカル保存は別になります。

## 保存されるもの

- 自動保存: 会話とフロー図の編集を約0.6秒後にブラウザのIndexedDBへ下書きとして保存し、再読み込み時に復元します。
- ブラウザに保存: 会話名を付けた別スナップショットを保存します。
- JSON出力/読込: 会話、各発言の感情・色・名前・プロフィール画像URL、直近300件の通信ログ、ノード・矢印・座標を扱います。音声、APIキー、OAuthアクセストークン、Googleメールアドレスは含めません。会話本文に機密情報を書けば、その本文は保存されます。共有前に内容を確認してください。
- Drive設定: APIキー・声・ロボの色・会話ディレクションを、Driveの隠しアプリ専用領域 `appDataFolder` に別ファイルとして保存します。初回は明示的な保存操作が必要です。`Drive設定を削除` はこのファイルだけを削除します。
- Drive同期: 「Drive同期を開始」を押すと現在の会話・図にファイルを作り、その後の編集を約3秒の待機後に同じファイルへ自動更新します。再読み込み後も、同じGoogleアカウント・同じ課題なら同期を再開します。別端末でファイルが更新された場合は自動上書きを止めます。
- Drive一覧: このアプリから保存した最新100件を表示します。読み込んだ課題は同じファイルへ同期を続けます。必要な権限は `drive.file` と `drive.appdata` です。
- 読込: 現在の表示を置き換えます。ローカル保存が利用できる場合、置換前の内容を「読込前の退避」として保存します。Live接続中は読み込めません。

上限は会話1000発言、各発言20000文字、ノード500件、矢印2000件です。長い会話は途中でJSON出力してください。保存データは表示を復元するもので、Geminiサーバー側の会話記憶は復元しません。

## セキュリティと注意点

- 「このブラウザに記憶」がONの場合、APIキーはlocalStorageに平文保存されます。Drive設定へ保存した場合も、APIキーはアプリ側で暗号化せずJSONとして保存されます。Googleによるアクセス制御はありますが、キーそのものを安全なサーバーに秘匿する方式ではありません。共有PCではブラウザへの記憶をOFFにしてください。
- 「ブラウザから削除」はローカルのAPIキーだけを消します。Drive上の設定は「Drive設定を削除」で別途消してください。
- Googleの短期アクセストークンはタブのsessionStorageにのみ保持します。有効期間を過ぎたらGoogleへ再接続してください。長期の自動ログインは行いません。
- ログアウトしても会話やAPIキーのローカル保存は残ります。Drive同期は停止し、再ログインで再開します。過去の発言の名前と画像は、その発言時のものを維持します。
- 同じ課題を複数端末で同時編集した場合、自動マージはしません。Drive上の更新を検知すると同期を止め、ブラウザの下書きは残します。読込前にJSON出力して差分を確認してください。
- `localhost` と `127.0.0.1`、ポート番号が異なるURLは別の保存領域です。
- ブラウザデータ削除・プライベートモード・ストレージ制限でローカル保存が失われる場合があります。重要な会話はJSONまたはDriveに保存してください。

公式資料: [GIS token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model)、[Drive uploads](https://developers.google.com/workspace/drive/api/guides/manage-uploads)。

## 開発時の検証

`node --test tests/live-session.test.js` と `npm run build`。
Vite起動中の `/tests/live-ui.html` はロボ18表情とチャット連結・保存復元を確認するテスト専用画面です。Google/Geminiへ接続せず、本番の保存領域を変更しません。
